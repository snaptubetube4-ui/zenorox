# Zonorox - Ecommerce Store

## Run
    npm install
    npm start
Store: http://localhost:3000   Admin: http://localhost:3000/admin
Admin password: zonorox123  (change it: ADMIN_PASSWORD=yourpass npm start)

## Features
- 7 categories, 36 products (shoes, watches, frames, laptop stands, electronics, home, beauty)
- Trending products tagged from Daraz / Alibaba bestseller lists
- Search, sort, price filter, pagination, cart drawer, free-delivery bar
- Checkout (COD, JazzCash, Easypaisa, Bank Transfer), order tracking
- Admin: dashboard, add/edit/delete products, order status, stock restore on cancel
- Data is stored in data/db.json (created on first run)

## Images
Product photos load from loremflickr.com by keyword. For exact photos, paste your own image URLs in Admin > Products > Edit.
